# تشغيل حلقتي على جهازك (حفظ محلي)

تعمل المنصة كاملة على كمبيوترك: قاعدة البيانات، وتسجيل الدخول، والواجهة. البيانات محفوظة على جهازك في مخزن Docker دائم، ولا تحتاج حسابًا في أي خدمة سحابية.

## المتطلبات
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) مثبّت ويعمل (ويندوز أو ماك أو لينكس).
- [Node.js 22](https://nodejs.org) لتشغيل أوامر الإدارة.
- نسخة من المستودع، ثم داخل مجلد `halaqati`: `npm install`.

## أول تشغيل
```bash
npm run local:setup -- بريدك@example.com   # ينشئ أسرارًا عشوائية في local/.env ويحفظ بريدك كمالك
npm run local:up                            # يبني ويشغّل كل شيء (أول مرة تأخذ بضع دقائق)
```
ثم افتح http://localhost:3000 وأنشئ حسابك بنفس البريد، فتحصل تلقائيًا على كل الأدوار (طالب، وليّ أمر، محفّظ، معلّم دورات، كفيل، إدارة المنصة) مع دار ومركز تجريبيين.

لتجربة المنصة بمستخدمين يتفاعلون: «إدارة المنصة» ← «البيانات التجريبية» ← إنشاء (ويُحذف كله بضغطة).

## الاستخدام اليومي
| الأمر | ماذا يفعل |
|---|---|
| `npm run local:up` | تشغيل المنصة |
| `npm run local:down` | إيقافها (البيانات تبقى) |
| `npm run local:backup` | نسخة احتياطية في مجلد `backups/` |
| `npm run local:restore -- backups/الملف.dump --yes` | استبدال البيانات بنسخة سابقة |
| `npm run local:logs` | متابعة السجلات عند وجود مشكلة |

تعمل المنصة تلقائيًا بعد إعادة تشغيل الجهاز طالما Docker يعمل.

## الوصول من الجوال في نفس الشبكة
شغّل الإعداد بعنوان جهازك في الشبكة، مثلًا:
```bash
npm run local:setup -- بريدك@example.com --site=http://192.168.1.20:3000
```
(إن كان `local/.env` موجودًا فعدّل السطر `SITE_URL` فيه)، ثم `npm run local:up` وافتح العنوان من الجوال.

## حدود الوضع المحلي
- لا يوجد بريد إلكتروني: الحسابات تُفعَّل مباشرة، و«نسيت كلمة المرور» لا يرسل رسالة. لتغيير كلمة مرور مستخدم استعمل حساب إدارة المنصة أو أعد إنشاء الحساب.
- إشعارات الجهاز (Web Push) ودخول Google يحتاجان نشرًا على الإنترنت؛ تظهر الإشعارات داخل المنصة كالمعتاد.
- لا تشارك ملف `local/.env` ولا ملفات `backups/`: فيها الأسرار وبيانات الطلاب.

## العودة للسحابة لاحقًا
الـ migrations نفسها في `supabase/migrations` تعمل على أي مشروع Supabase. أنشئ مشروعًا، طبّقها بالترتيب، ثم انقل البيانات بنسخة `pg_dump` من جهازك.
