# حالة التنفيذ

## المرحلة الأولى: التأسيس ✅
- مشروع Next.js 16 + TypeScript + Tailwind، واجهة عربية RTL بخط Cairo وهوية حلقتي والشعار الرسمي.
- التسجيل، وتسجيل الدخول، والخروج، واستعادة كلمة المرور، وتأكيد البريد، مع تحديد معدل المحاولات.
- نظام أدوار متعددة لكل حساب، مع مبدّل سياق آمن.
- المؤسسات والمراكز والعضويات مع العزل الكامل (RLS)، وتوثيق المؤسسات من إدارة المنصة.
- الملف الشخصي، والإشعارات، وسجل التدقيق، وطلبات الخصوصية، ولوحة إدارة المنصة.
- ربط وليّ الأمر برمز لمرة واحدة.

## المرحلة الثانية: الحلقة القرآنية ✅
- إنشاء الحلقات المستقلة (والتابعة لمركز لمن يملك العضوية)، والنشر، والتصفح العام مع البحث والتصفية والتقسيم إلى صفحات.
- طلبات الانضمام: قبول واعتذار، والسعة، والانسحاب، وإنهاء العضوية.
- الجلسات (مع رابط الاجتماع للأعضاء فقط)، والحضور الجماعي.
- تسجيل التسميع: النطاق، ونوع النشاط، والإنجاز، والإتقان، وجودة التلاوة، والالتزام، والأخطاء، والملاحظات، والمسودة والاعتماد، والتعديل الموثّق.
- الواجب القادم وربطه بالتسميع تلقائيًا.
- لوحات: الطالب (رحلتي، خطتي، جلساتي، حلقاتي)، المحفّظ، وولي الأمر (الأبناء وتفاصيل كل ابن).

## إضافات مستوحاة من مخطط TechMood ✅
- جدول أسبوعي للطالب وللمحفّظ، وجدول الطلاب لكل حلقة (الحضور، الحفظ، المراجعة، الإتقان، التلاوة، آخر تسميع، الواجب القادم).
- زر «انضم إلى اللقاء» يظهر قبل الموعد بعشر دقائق.
- بطاقة ترحيب ملوّنة حسب الدور مع الإجراء الأهم، وقائمة «خطواتك الأولى».
- سلسلة الالتزام الأسبوعية (خاصة بالطالب وولي الأمر والمحفّظ، دون لوحة ترتيب عامة حمايةً للأطفال).
- توثيق المحفّظين ✓ بمراجعة إدارة المنصة.
- شهادات إنجاز برقم فريد، وصفحة تحقق عامة، ورمز QR، ومشاركة وطباعة، مع إخفاء اسم الطالب افتراضيًا.
- مركز المساعدة والبلاغات مع قائمة للإدارة.
- تثبيت المنصة كتطبيق (PWA)، وفتح الصفحات العامة دون اتصال.
- لم يُنقل من المخطط: الدفع والمحفظة والعمولات (ينتظر قرار مزوّد الدفع)، والمساعد الذكي (يحتاج مفتاح API مدفوعًا)، والسوق وStartup Studio (خارج نطاق منصة قرآنية).

## يحتاج إعدادًا خارجيًا
- مشروع Supabase `halaqati` (adoohwswgvajeyzkhhnf، فرانكفورت) أُنشئ، وطُبّقت عليه migration الأساس وجدول السور فقط؛ الباقي (0200 جزء 2، 0300، 0400) لم يُطبّق بعد.
- النشر على Vercel: محجوب من بيئة العمل هذه (الشبكة لا تسمح بـ api.vercel.com).
- خادم SMTP لرسائل التأكيد والاستعادة.
- إنشاء أول مدير للمنصة (`private.bootstrap_platform_admin`).
- مراجعة قانونية لنصوص الخصوصية والشروط (المكتوبة نسخة أولية).

## المتبقي
- **المرحلة 3**: واجهات أمير المركز ومدير الدار، والدعوات (`InstitutionInvitation`) وتفعيل «الانضمام بالدعوة»، وتوزيع الطلاب والمحفّظين، والمساعدون، والتقارير الإدارية ومقارنة الفروع.
- **المرحلة 4**: الدورات (الوحدات، الدروس، الموارد، التسجيل، الواجبات، الاختبارات، الشهادات). صورة التصميم المرجعية (صفحة الدورة والفيديو والشهادة) محفوظة كمرجع لهذه المرحلة.
- **المرحلة 5**: برامج الكفالة وطلباتها والتزاماتها وتقاريرها المحدودة، مع فصل أموال الكفالات عن المحاسبة التشغيلية. لا دفع حقيقي قبل تحديد المزوّد والعملة والسياسات.
- **المرحلة 6**: تصدير البيانات آليًا، وبيانات تجريبية منفصلة، وتنظيف الإشعارات المجدول، ومراجعة الأداء على بيانات كبيرة، وتوليد أنواع TypeScript من القاعدة.
