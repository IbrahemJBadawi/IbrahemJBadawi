# الاختبارات

## التشغيل
```bash
npm run test:unit                     # لا يحتاج أي خدمة
npm run test:db                       # يحتاج PostgreSQL 15+ (TEST_DATABASE_ADMIN_URL)
E2E_BASE_URL=http://localhost:3000 npm run test:e2e              # الصفحات العامة
E2E_FLOW=1 E2E_BASE_URL=http://localhost:3000 npm run test:e2e   # التدفق الكامل (يحتاج backend مع تأكيد بريد تلقائي)
npm run build && npm run check:secrets
```
تنشئ اختبارات قاعدة البيانات قاعدة مؤقتة، وتطبّق `supabase/tests/local-supabase-shim.sql` (محاكاة لأدوار Supabase ودالة `auth.uid()`) ثم الـ migrations الحقيقية، وتنفّذ الاستعلامات بهوية كل مستخدم كما يفعل Supabase. أي أن سياسات RLS تُختبر فعليًا.
